# OpenGUI-Plus 全量教程中心

> 从零开始，到十模块组合成一条可复用、可调度、可回放的 Android 自动化流水线。

OpenGUI-Plus 的源码和上游 OpenGUI 是两层：上游负责 Android GUI Agent 的观察、规划和执行；本增强层位于 `deepseek-harness-plugin/opengui-plus/`，提供连接、资产管理、模板、调度、项目隔离、经验沉淀、设备池和回放能力。本教程专门讲增强层，所有示例都以 CLI 为主，同时标注控制台和 DSH 的对应入口。

## 你会学到什么

完成本目录后，你应该能独立完成以下闭环：

1. 用 USB、WiFi 或自动模式连接 Android 设备。
2. 把常用操作保存为带别名、标签和说明的指令。
3. 录制 `connect / launch / tap / swipe / input / shell / screenshot / wait / snippet / disconnect` 等动作。
4. 用 `{{变量}}` 把模板改成可复用流程。
5. 用单次、每日、每周或 Cron 计划执行流程。
6. 用项目组隔离不同业务的设备、模板和配置。
7. 用人工示范和反馈经验迭代流程。
8. 用工作流文件迁移和分享模板。
9. 把任务放进设备池，让空闲设备自动接单。
10. 用逐帧 HTML 回放追查“哪一步、为什么失败”。

## 快速索引：最常用命令

```bash
# 构建
cd deepseek-harness-plugin/opengui-plus
npm install
npm run build

# 查看模块和方法
node lib/cli.js modules

# 任意模块调用
node lib/cli.js call <module>.<method> --json '{"key":"value"}'

# 启动网页控制台
node lib/cli.js serve --host 127.0.0.1 --port 8787
```

Windows PowerShell 把单引号保留即可；CMD 建议把 JSON 改为双引号包裹并转义内部双引号，或优先使用 `--key value` 逐项传参。

## 阅读约定

- `<id>`、`<sessionId>`、`<templateId>` 是上一步命令返回的真实 ID，不能原样复制。
- `--json` 适合传数组、对象和嵌套结构；简单字符串优先用 `--key value`。
- CLI 成功时打印结果对象；失败时在 stderr 打印 `错误:` 并返回非零退出码。
- 没有设备或没有 DSH 时，部分动作会以“降级 / skipped / 记录但未执行”方式返回。这是为了让本地开发和测试不被真机阻塞，不代表真机动作已经完成。
- 教程中的示例设备地址、包名、账号和任务内容都只是占位示例，使用前替换成自己的值。
