# 03. 模块二：快捷指令库 `snippet-library`

## 目标

把常用长指令保存为短别名，支持标签、描述、使用次数、前缀补全和 JSON 迁移。首次启动空项目会写入内置示例指令。

## 1. 查看内置指令

```bash
node lib/cli.js call snippet-library.list
node lib/cli.js call snippet-library.listTags
```

筛选：

```bash
node lib/cli.js call snippet-library.list --tag 调试
node lib/cli.js call snippet-library.list --query 截屏
```

## 2. 新增指令

```bash
node lib/cli.js call snippet-library.save --json '{
  "alias":"health",
  "command":"检查当前设备连接、前台 Activity 和屏幕状态",
  "tags":["巡检","调试"],
  "description":"每天巡检设备时使用"
}'
```

别名规则：

- 必须唯一。
- 不能含空白。
- 不能含 `/` 等路径字符。
- 建议只使用小写字母、数字、短横线和下划线。

## 3. 更新和删除

新增结果中的 `id` 可用于更新：

```bash
node lib/cli.js call snippet-library.save --json '{
  "id":"snp_xxx",
  "alias":"health",
  "command":"检查连接、前台 Activity、截图并记录结果",
  "tags":["巡检","调试"],
  "description":"更新后的巡检指令"
}'
```

删除可以用 id 或 alias：

```bash
node lib/cli.js call snippet-library.remove --alias health
```

## 4. 解析和自动补全

```bash
node lib/cli.js call snippet-library.resolve --alias health
node lib/cli.js call snippet-library.complete --prefix he
node lib/cli.js call snippet-library.complete --prefix ''
```

`resolve` 会返回完整 command，并把 `useCount` 加一；补全结果按使用次数优先，适合在 DSH 对话中先补全再执行。

## 5. 导出与导入

导出：

```bash
node lib/cli.js call snippet-library.exportJson > snippets.json
```

导入前注意：CLI 的输出可能包含格式化 JSON；把文件内容作为 `payload` 传给模块：

```bash
node lib/cli.js call snippet-library.importJson --json '{
  "payload":{"version":1,"snippets":[
    {"alias":"health","command":"检查设备健康状态","tags":["巡检"]},
    {"alias":"report","command":"整理本次执行结果","tags":["报告"]}
  ]},
  "mode":"merge"
}'
```

两种模式：

- `merge`：按 alias 合并；已有 alias 更新，新 alias 追加；本地 id 保留。
- `replace`：先校验整个数据包，再整体替换。校验失败不会破坏原数据。

## 6. 与动作模板组合

可以把一个 snippet 作为模板步骤：

```json
{
  "type": "snippet",
  "params": { "alias": "health" },
  "note": "调用快捷指令做巡检"
}
```

执行模板时，`action-template` 会通过模块调用解析该 alias。这样可以集中维护 command，而不用每个模板重复写长文本。

## 7. 与定时任务组合

调度目标使用 `type: snippet` 并指向 alias：

```json
{
  "name":"每日巡检",
  "schedule":{"kind":"daily","at":"09:30"},
  "target":{"type":"snippet","alias":"health"},
  "enabled":true
}
```

具体创建命令见 [定时任务教程](./05-模块四-定时任务.md)。

## 8. 控制台和 DSH

控制台中可以搜索、按标签筛选和编辑指令。DSH 中可以说：

```text
请调用 snippet-library.complete，prefix 为 health；只返回候选，不要执行。
请调用 snippet-library.resolve，alias 为 health，然后把完整指令展示给我。
```

## 9. 迁移注意

- 导出的 JSON 是数据包，不是 shell 脚本，不要直接执行。
- 导入前建议先导出当前库作为回滚备份。
- 不要把密码、Token、私有 IP 写入可公开分享的指令库。
- 项目作用域的 snippet 随项目组切换；跨项目通用的资产建议复制到各项目，或通过项目组导出迁移。
